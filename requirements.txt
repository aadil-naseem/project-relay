# =============================================================================
# RELAY - Factory Continuity Desk
# Complete dependency list for a fresh clone.
# =============================================================================
#
# There are TWO toolchains in this repo:
#
#   1. Python  -> the FastAPI backend   (this file)
#   2. Node.js -> the React + Vite SPA  (frontend/package.json)
#
# -----------------------------------------------------------------------------
# 1. Backend setup (Python 3.12)
# -----------------------------------------------------------------------------
#
# Windows PowerShell, from the repo root:
#
#   py -3.12 -m venv backend\.venv
#   backend\.venv\Scripts\python.exe -m pip install --upgrade pip
#   backend\.venv\Scripts\python.exe -m pip install -r requirements.txt
#   backend\.venv\Scripts\python.exe backend\scripts\reset_demo.py
#
# macOS / Linux, from the repo root:
#
#   python3.12 -m venv backend/.venv
#   backend/.venv/bin/python -m pip install --upgrade pip
#   backend/.venv/bin/python -m pip install -r requirements.txt
#   backend/.venv/bin/python backend/scripts/reset_demo.py
#
# Then run the API (from backend/):
#
#   .venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
#
# No API key is required. Weather runs on replay data and drawings are answered
# from a committed golden cache, so the demo works fully offline.
#
# -----------------------------------------------------------------------------
# 2. Frontend setup (Node.js 20+; tested on Node 24)
# -----------------------------------------------------------------------------
#
#   cd frontend
#   npm ci            # exact versions from package-lock.json (npm install also works)
#   npm run dev
#
# Frontend runtime libraries (versions live in frontend/package.json):
#   react, react-dom, react-router-dom, @tanstack/react-query, zustand,
#   vite, @vitejs/plugin-react, three, @react-three/fiber, @react-three/drei,
#   gsap, lenis, recharts, leaflet, react-leaflet,
#   @fontsource/{ibm-plex-sans,ibm-plex-mono,big-shoulders-display,instrument-serif}
# Frontend dev tools: oxlint, @types/react, @types/react-dom
#
# -----------------------------------------------------------------------------
# Notes on scope
# -----------------------------------------------------------------------------
#
# * Versions below are pinned to the ones this release (v1.0) was tested with,
#   so a clone reproduces the same environment. They are also listed unpinned in
#   backend/requirements*.txt, which is what the hosted deploy installs.
# * The hosted backend build installs backend/requirements.txt (runtime only).
#   This root file adds the test and lint tools on top.
# * backend/requirements-data.txt and backend/requirements-optional.txt are
#   NOT needed to run the app - see the optional section at the bottom.
#
# =============================================================================
